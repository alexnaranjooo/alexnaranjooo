## 🚀 Proyectos destacados

### 🍯 HoneyNet — TFG de ciberseguridad *(en desarrollo)*

**Descripción:** infraestructura empresarial simulada para detectar y analizar intrusiones reales.

**Tecnologías:** Proxmox, pfSense, VLANs, Docker, Cowrie, Dionaea, DVWA, Wazuh, Grafana, Python.

**Características principales:**
- 🔐 Red segmentada en VLANs (DMZ, servidores, gestión y usuarios)
- 🍯 Honeypots que capturan ataques SSH, malware y ataques web
- 📊 SIEM y dashboard en tiempo real
- 🤖 Respuesta automática con Python (bloqueo de IPs y alertas)

👉 [Ver repositorio](https://github.com/alexnaranjooo/PROYECTO-HONEYNET)

### 🌐 Empresa AlwaysOn — Proyecto de redes

**Descripción:** diseño e implementación de la red de una empresa ficticia aplicando lo aprendido en ASIX.

**Tecnologías:** GNS3, Cisco Packet Tracer, Cisco IOS.

**Características principales:**
- 🏢 Segmentación por departamentos con VLANs y enrutamiento entre VLANs
- 🌍 Routing dinámico con OSPF
- 🔐 ACLs, Port Security y NAT
